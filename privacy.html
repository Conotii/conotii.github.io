Privacy Policy – Studio

Last updated: 19 November 2026 · Deutsche Version

Who uses Studio

Studio is a private tool operated by a single person to manage their own YouTube channels. It is not offered to the public, and there is no sign-up. The only Google accounts connected to Studio belong to the operator.

What data Studio accesses

When a channel is connected through Google sign-in, Studio requests these read-only permissions:

  • youtube.readonly – channel name and ID, list of the channel's videos and their public details.
  • yt-analytics.readonly – analytics of the connected channel (views, watch time, retention, subscribers, impressions and click-through rate).
  • yt-analytics-monetary.readonly – estimated revenue of the connected channel, if it is monetized.

Studio does not upload, change or delete any content and does not access email, contacts, Drive or any other Google data.

How the data is used

The data is used only to show statistics of the connected channels inside Studio's dashboard to the operator. It is not sold, not shared with third parties, not used for advertising and not used to train AI models.

Storage and security

Access tokens and the retrieved statistics are stored on the operator's own server in a private network. They are not sent to any other service.

Deleting data and revoking access

Access can be revoked at any time in Studio ("Disconnect"), which deletes the stored tokens, or in the Google account under myaccount.google.com/permissions. Stored statistics are deleted on request.

Google API Services User Data Policy

Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Studio also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions about this policy can be sent to the support email address shown on Studio's Google sign-in screen.

Datenschutzerklärung – Studio

Stand: 19. November 2026

Wer Studio nutzt

Studio ist ein privates Werkzeug, das von einer einzelnen Person zur Verwaltung ihrer eigenen YouTube-Kanäle betrieben wird. Es wird nicht öffentlich angeboten, eine Registrierung gibt es nicht.

Welche Daten Studio abruft

Beim Verbinden eines Kanals über die Google-Anmeldung fragt Studio nur lesende Berechtigungen an: Kanalname und Videoliste (youtube.readonly), Statistiken des Kanals wie Aufrufe, Wiedergabezeit, Abonnenten, Impressionen und Klickrate (yt-analytics.readonly) sowie geschätzte Einnahmen, falls der Kanal monetarisiert ist (yt-analytics-monetary.readonly). Studio lädt nichts hoch, ändert oder löscht nichts und greift auf keine anderen Google-Daten zu.

Wofür die Daten genutzt werden

Ausschließlich, um dem Betreiber die Statistiken seiner Kanäle im Dashboard anzuzeigen. Keine Weitergabe, kein Verkauf, keine Werbung, kein KI-Training.

Speicherung

Zugangsschlüssel und Statistiken liegen auf dem eigenen Server des Betreibers in einem privaten Netzwerk.

Löschen und Widerruf

Der Zugriff kann jederzeit in Studio („Trennen“) oder unter myaccount.google.com/permissions widerrufen werden. Gespeicherte Statistiken werden auf Wunsch gelöscht.

Google-Richtlinien

Die Nutzung von Daten aus Google-APIs entspricht der Google API Services User Data Policy einschließlich der „Limited Use“-Anforderungen.

Kontakt

Fragen an die Support-E-Mail-Adresse, die auf dem Google-Anmeldebildschirm von Studio angezeigt wird.
